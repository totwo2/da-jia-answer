# 对比结果模板

## 通用多栏对比模板（栏数自适应）

```
╔══════════════════════════════════════════════════════════════════╗
║  📊 问题：{question}                                        ║
╠══════════{col_sep}╦══════════{col_sep}╦══════════{col_sep}╣
║ [{label_a}] {name_a}  ║ [{label_b}] {name_b}  ║ [{label_c}] {name_c}  ║
╠══════════{col_sep}╬══════════{col_sep}╬══════════{col_sep}╣
║ {answer_a}          ║ {answer_b}          ║ {answer_c}          ║
╚══════════{col_sep}╩══════════{col_sep}╩══════════{col_sep}╝
```

**说明**：
- `{col_sep}` = `═` × 10（栏数不足 3 时自适应宽度）
- `{label_a/b/c}` = A/B/C/D…（按选中顺序自动编号）
- `{name_a/b/c}` = 模型显示名（如 gpt-4o / qwen-max）
- 回答超长时每栏独立截断，末尾加"…"
- 某栏失败时：该格显示 `❌ {error}`，其余正常

## 紧凑双栏模板（仅 2 个模型时）

```
╔══════════════════════════════════════════════════════════════════╗
║  📊 问题：{question}                                        ║
╠══════════════════╦══════════════════╣
║ [A] {name_a}      ║ [B] {name_b}      ║
╠══════════════════╬══════════════════╣
║ {answer_a}        ║ {answer_b}        ║
╚══════════════════╩══════════════════╝
```
